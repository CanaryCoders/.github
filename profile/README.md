# CanaryCoders

**Software designed, built and hosted in the Canary Islands**

A family tech studio in Lanzarote. We build web and mobile apps for local
businesses and run our own products, from a mobile office that travels the
islands.

- **[CanaryPulse](https://canarypulse.es)**: a live guide to the Canary Islands.
  Weather, sea conditions, beaches, trails and places to eat, plus an AI
  assistant that answers questions about the islands.
- **[CanaryFactura](https://canaryfactura.es)**: invoicing for Canarian
  freelancers and small businesses, with per-line IGIC, IRPF withholding and
  VERI\*FACTU submission to the AEAT.
- **[CanaryLytics](https://analytics.canarycoders.es)**: cookieless web
  analytics. No IP, no cookies, no fingerprint, no consent banner.
- **[CanaryCoders AI](https://ai.canarycoders.es)**: a multi-provider AI gateway
  for chat, embeddings, vision and media generation.
- **[Vereda](https://veredamaps.com)**: guest wayfinding for resorts, parks and
  festivals, built from our work for Club La Santa.

Client work includes [Club La Santa](https://www.clublasanta.com) and
[Be Fit 2 Sail](https://befit2sail.com).

**Open source:** [canaryllm-sdk](https://github.com/CanaryCoders/canaryllm-sdk)
(TypeScript SDK for the gateway),
[canaryllm-rag](https://github.com/CanaryCoders/canaryllm-rag) (RAG toolkit that
keeps your vectors on your own infrastructure),
[CanaryCodeCli](https://github.com/CanaryCoders/CanaryCodeCli) (a terminal
coding agent).
